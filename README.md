# Full-Stack Web Application (CA-03)
**PRN:** 25070521321  
**Section:** SEC-C  

## Project Structure
- `/client` — React + Vite frontend
- `/server` — Node.js, Express, and MongoDB backend

## Setup & Running Locally

### Backend
1. `cd server`
2. `npm install`
3. Ensure MongoDB Compass / daemon is running on `mongodb://127.0.0.1:27017`
4. `npm run dev` (Runs on port 5000)

### Frontend
1. `cd client`
2. `npm install`
3. `npm run dev` (Runs on port 5173)

## Features
- Full CRUD operations connected to MongoDB
- User Authentication (Signup & Login)
- Multi-page responsive layout
